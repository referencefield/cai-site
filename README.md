# Compliance as Infrastructure Site

## Repository bootstrap

Read `00_REPOSITORY_PROFILE.yaml` before modifying this repository. For cross-repository or shared-architecture work, follow its canonical J Space governance links.

This public Docusaurus site publishes the Compliance as Infrastructure (CAI) manuscript, architecture, diagnostics, readiness models, crosswalks, and operational extensions.

## Primary content

- `docs/` - published CAI content
- `docusaurus.config.js` - site configuration
- `package.json` - build and dependency definition

Changes to CAI architecture that may affect prototypes, reviews, or shared governance require cross-repository impact review under the global repository hygiene protocol.
