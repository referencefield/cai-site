# Extensions

The CAI manuscript defines the structure of Compliance as Infrastructure.

The Extensions layer exposes that structure as usable system interfaces.

These documents are not explanatory.

They are operational.

---

## What This Layer Is

Each artifact in this section performs a specific function:

- Defines the category boundary  
- Tests whether governance exists  
- Classifies governance capability  
- Evaluates other frameworks against execution reality  

They are designed to be applied directly.

---

## What This Layer Is Not

These are not:

- narrative explanations  
- introductory material  
- implementation guides  

They do not describe CAI.

They operate on systems using CAI.

---

## How to Use This

Each document can be used independently.

- The Diagnostic Tool tests a system  
- The Readiness Model classifies a system  
- The Crosswalk evaluates governance frameworks  
- The Positioning Statement defines category boundaries  

Use them where a decision, evaluation, or claim needs to be made.

---

## Relationship to the Manuscript

The manuscript establishes the theory.

This layer applies it.

---

Governance is not described here.

It is tested.
